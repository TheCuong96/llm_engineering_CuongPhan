## 5. Bước tiếp theo đề xuất

1. Mở [01-goi-api-va-prompt-co-ban-chi-tiet.md](01-goi-api-va-prompt-co-ban-chi-tiet.md) và đọc từ đầu.
2. Nếu chưa hoàn tất cài đặt môi trường (`uv sync`, file `.env` với `OPENAI_API_KEY`), làm theo [setup/SETUP-new.md](../setup/SETUP-new.md) trước khi thực hành phần gọi API thật (phần lý thuyết vẫn đọc được mà không cần cài đặt).
3. Nếu không muốn dùng API trả phí, có thể dùng bản thay thế miễn phí bằng Ollama tại `week1/solutions/day1_with_ollama.ipynb` (bạn tự chạy, tôi không chạy hộ vì đây là thao tác cần bạn tự thực hiện).
4. Làm phần "Hướng dẫn thực hành" và 3 bài tập nhỏ ở cuối Bài 01.
5. Báo lại kết quả/câu trả lời (kể cả khi sai hoặc chưa chắc) để tôi cập nhật mục 2-4 ở trên và tạo Bài 02.
